Direction B spends its one risk on a non-text visual in every row: the window track turns the day's delivery load into something you can read down the column — early-morning loads cluster left, evening drops sit right. It is justified because the operator's core question is when, across the day, are my deliveries. Cards float on a warm field with soft navy depth so the table reads like a premium dispatch sheet, not a spreadsheet. Honours D1–D4.
